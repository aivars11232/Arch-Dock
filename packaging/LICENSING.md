# Arch Dock package licensing declarations

The repository currently has no project-wide license declaration. The local
Arch package records this as `LicenseRef-Arch-Dock-Unspecified`; this notice
does not select a license for the project.

The Plasma applet, layout-template and KWin component metadata retain their
existing MIT declarations. Installed theme and icon-style manifests retain
their individual `license` records, including redistribution evidence and
`NOASSERTION` where no public SPDX license was selected by the owner.

Read the declarations associated with the component or resource in question.
The resource manifests are installed under `/usr/share/arch-dock/themes/`
and `/usr/share/arch-dock/icon-styles/`. Package preparation does not rewrite
those declarations or grant an additional project-wide license.
